# 🦅 سورس ريكو المطور — V16

يوزربوت تيليجرام (Telethon) بنظام تنصيب عبر بوت، يدعم عدة حسابات بنفس العملية.

## التشغيل
```bash
pip install -r requirements.txt
sudo apt install ffmpeg          # للدقات العالية وMP3 بأمر .يوت
python app.py
```
الإعدادات (التوكن و API) بـ `config.py` أو ملف `.env` بجانب `app.py`:
```
RECO_BOT_TOKEN=...
RECO_API_ID=...
RECO_API_HASH=...
GEMINI_API_KEY=...        # اختياري: يقوّي أمر .ذكاء
```

## ⚠️ مهم: تفعيل أزرار inline (مرة وحدة)
أزرار `.يوت` و `.اوامر` تُرسل عبر البوت الرئيسي. فعّلها من **@BotFather**:
`/setinline` ← اختر البوت ← اكتب أي نص (مثلاً `ريكو`).
بدون هذا الإعداد السورس يشتغل عادي، لكن `.يوت` ينزّل صوت مباشرة و`.اوامر` تظهر نصاً.

## `.يوت` — تحميل بالأزرار
```
.يوت اسم الاغنية                 ← بحث + أزرار: 🎬 فيديو / 🎧 صوت ← الدقة أو الصيغة
.يوت <رابط>                      ← يوتيوب، انستا، تيك توك، تويتر ...
.يوت صوت اسم                     ← MP3 مباشرة      .يوت فيديو اسم 720   ← فيديو بدقة محددة
.تحديث_يوت                       ← تحديث محرك yt-dlp (يحل أغلب أعطال التحميل)
```
لو يوتيوب طلب «تأكيد أنك لست روبوت» ضع ملف `cookies.txt` (تصدير كوكيز المتصفح) بجانب `app.py`.

## هيكل المشروع
```
app.py            بوت التنصيب + لوحة المطور + الاشتراكات
user_core.py      تشغيل حساب واحد
config.py         الإعدادات
core/
  framework.py    موزّع الأوامر (@command) + الأخطاء المفهومة + العدّاد
  catalog.py      القوائم (.م1 …) تتولّد تلقائياً من الأوامر
  ui.py           كلايش وتنسيقات موحّدة
  bridge.py + inline_bot.py   جسر الأزرار الشفافة عبر البوت الرئيسي
  yt.py           محرك التحميل
  state.py + context.py       حفظ حالة كل حساب (data/<id>/state.json)
  constants.py    اسم المطور والقناة... (غيّرها من هنا فقط)
plugins/<قسم>/   الأوامر (كل ملف = مجموعة أوامر مترابطة)
tools/selftest.py  اختبار ذاتي — شغّله بعد أي تعديل
```

## إضافة أمر جديد (30 ثانية)
أنشئ ملف `plugins/tools/my_cmd.py`:
```python
from core.framework import command

@command(".هلو", section="fun", desc="يسلم عليك", usage=".هلو [اسم]")
async def hello(cmd):
    await cmd.edit(f"هلا بيك {cmd.args or 'يا غالي'} 👋")
```
وخلاص — يظهر بالقوائم تلقائياً. ما تحتاج تسجيله بأي مكان.
- `cmd.args` النص بعد الأمر · `await cmd.target()` الشخص (رد/@يوزر/ايدي) · `cmd.need(شرط, "رسالة")` · `cmd.edit()`
- `helpers=True` يسمح للمساعدين · `scope="group"` للمجموعات فقط · `numeric_suffix=True` يقبل `.امر5`
- ميم جديد: أضف سطر بـ `plugins/memes/memes.json`.

## نظام الاشتراكات (اختياري)
